# 🛒 MealOptimizer  
**Generador inteligente de menús semanales + comparador de precios reales**  
_Proyecto full-stack con OCR e IA basada estrictamente en datos reales._

---

## 📌 Descripción
**MealOptimizer** es una aplicación web que genera **menús semanales personalizados** según:

- Presupuesto  
- Número de personas  
- Preferencias y alergias  
- Tienda favorita  
- Precios reales obtenidos de tickets escaneados  
- Recetas validadas del catálogo interno  

Este proyecto combina:

✅ Backend real  
✅ Frontend real  
✅ Base de datos viva  
✅ OCR para extraer precios de tickets  
✅ IA **con restricciones**, sin inventar datos  
✅ Comparador de coste entre tiendas  
✅ Sistema de confianza y “frescura” de precios  

El objetivo es minimizar la diferencia entre **precio real** y **precio almacenado**.

---

## 🎯 Objetivo del proyecto
- Planificación de comidas semanal bajo presupuesto realista.  
- Datos reales: precios actualizados a partir de tickets.  
- Plataforma ligera pero profesional para portfolio.  
- Arquitectura modular y escalable.
